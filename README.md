Pokedex - Aplicación Web con Django

Aplicación web desarrollada con Python y Django, inspirada en una Pokédex, que permite explorar y consultar información de diferentes Pokémon.

Tecnologías utilizadas
Python
Django
HTML
CSS
JavaScript
SQLite (si utilizaste la base de datos predeterminada de Django)
Requisitos previos

Antes de ejecutar el proyecto necesitas tener instalado:

Python
Git
Visual Studio Code (opcional)
Instalación
1. Clonar el repositorio

Abre una terminal y ejecuta:

bash
git clone https://github.com/LegnaF/Pokedex.git

2. Entrar a la carpeta del proyecto
bash
cd Pokedex

3. Crear un entorno virtual
bash
python -m venv venv

4. Activar el entorno virtual

En Windows PowerShell:

bash
.\venv\Scripts\Activate.ps1


Si utilizas CMD:

bash
venv\Scripts\activate

5. Instalar las dependencias
bash
pip install -r requirements.txt

6. Ejecutar las migraciones
bash
python manage.py migrate

7. Iniciar el servidor
bash
python manage.py runserver

8. Abrir el proyecto

En tu navegador ingresa a:

http://127.0.0.1:8000/
